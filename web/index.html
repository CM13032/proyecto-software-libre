Tecnologias utilizadas

Linux: Sistema operativo libre.

Docker: Plataforma de contenedores.

Nginx: Servidor web.

Git: Control de versiones.

GitHub: Repositorio colaborativo.

Objetivo del proyecto

Implementar un servidor Linux automatizado, utilizando contenedores Docker y aplicando conocimientos de administracion de sistemas, virtualizacion y control de versiones.
